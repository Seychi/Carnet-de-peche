## Détails & preuves

### 1. Fiches espèces ✅
Toutes affichent « Meilleurs spots ». Exemples de spots listés :
- **barracuda** : Antibes (06), Bastia (2B), Bonifacio (2A), Cap Béar (66), Cap Camarat (83), Ajaccio (2A).
- **tassergal** : Cap d'Antibes (06), Cap d'Agde (34), Cap Couronne (13), Barcaggio (2B), Cap Béar (66), Cap Camarat (83).
- **liche** : Antibes (06), Bandol (83), Marseille (13), Le Grau-du-Roi (30), Ajaccio/Bonifacio (2A).
- **marbré** : Paulilles (66), Fos-sur-Mer (13), Frontignan (34), Gruissan/La Franqui (11), Le Grau-du-Roi (30) — plages méditerranéennes.
- **lieu-noir** : Carteret/La Hague/Diélette (50), Cap Fréhel (22), Cap Sizun (29), Belle-Île (56).
- **merlan** : Boulogne/Calais/Gris-Nez (62), Dunkerque (59), Dieppe (76), Courseulles (14).

### 2. Filtres carte ✅
Filtre appliqué espèce par espèce (compte itinérant) → comptes de spots non nuls, identiques aux 6 totaux de la migration 094. 5 des 6 chips sont visibles d'emblée ; « Marbré » apparaît dès qu'il est sélectionné (les chips dérivent des markers chargés, comportement S52, pas un bug).

### 3. alose ✅ (+ note)
Spots vérifiés en base (Anglet/Adour, Hendaye baie de Txingudi, Port-Médoc, Plage d'Hendaye) : **aucun** n'a `alose` dans `species`. Sur la fiche live (Anglet), les chips espèce sont Bar/Maigre/Mulet/Sole/Dorade royale, tous cliquables, **pas de chip alose**.
**Note (non bloquante)** : le mot « alose » subsiste dans **une phrase de la description éditoriale** du spot Anglet (« L'alose remonte au printemps. ») et son sérialisé JSON-LD. C'est de la prose descriptive légitime (l'Adour est connu pour la remontée d'alose), **pas** l'espèce grise non cliquable visée par le correctif. À scrubber si tu veux être 100 % « hors référentiel », mais ce n'est pas un KO.

### 4. Garde date prise ✅
Form `/carnet/nouvelle` : l'input date est `datetime-local` avec `max="2026-06-30T08:20"` (= maintenant) → le sélecteur empêche le futur. Garde serveur confirmée dans `lib/catches/schema.ts` (`caught_at.refine(notFuture)` → message exact) avec tolérance +24 h (`lib/validation/date-guards.ts`, pour absorber le fuseau navigateur↔UTC). *Le refus serveur « si forcé » n'a pas été déclenché en live pour ne pas créer de prise ; la garde + le message sont vérifiés dans le code.*

### 5. Gardes date sortie ✅
- **Co-pêchage** (`/sorties` → « Proposer une sortie ») : input `datetime-local` **min = maintenant** → empêche le passé. Serveur : `lib/cofishing/schema.ts` `planned_at.refine(notPast)` → « La sortie doit être à venir (pas dans le passé). ».
- **Sortie solo** (`/carnet/sortie`, champ « Quand ») : input `datetime-local` **max = maintenant** → empêche le futur. Serveur : `lib/outings/schema.ts` `started_at.refine(notFuture)` → « Une sortie ne peut pas être dans le futur. ».

### 6. Prise mesurée ✅ (vérifié en live)
Toggle « Prise mesurée » → révèle « Longueur mesurée (cm) » (`number`, **min=10 max=250**) + « Objet de référence » (texte). La « Taille (cm) » générale reste `size_cm` (10-200, champ distinct). Submit avec « Prise mesurée » cochée et champs vides → **bloqué** avec les deux messages exacts (`refineMeasured`, `lib/catches/schema.ts`) :
> « Renseigne la longueur mesurée (ou décoche « Prise mesurée »). »
> « Indique l'objet de référence visible sur la photo (ou décoche « Prise mesurée »). »
Aucune prise créée (resté sur le formulaire).

### 7. Username insensible à la casse ✅
Sur `/profil`, pseudo remplacé par « shw » (variante de casse de « SHW », qui existe) puis « Mettre à jour mon profil ». Résultat : **pseudo de Seychi inchangé en base** (toujours « Seychi », vérifié par requête sur son id) → la variante a bien été refusée. Défenses confirmées :
- App : `app/(app)/profil/actions.ts` → `.ilike('username', pattern)` (avec échappement de %,_,\) `.neq('id', user.id)` → « Ce pseudo est déjà utilisé. ».
- Base : `CREATE UNIQUE INDEX profiles_username_lower_key ON profiles (lower(username)) WHERE username IS NOT NULL` (migration 096).
*Le toast d'erreur à l'écran n'a pas pu être capturé (renderer en timeout pendant l'action serveur), mais le refus lui-même est prouvé (aucun changement en base). Champ remis à « Seychi », brouillon abandonné.*
