La communauté

Une communauté qui partage le savoir, pas les spots.

Anti-fishbrain : les prises se partagent (avec floutage GPS), les techniques s'échangent, mais les coins secrets restent secrets. Une charte stricte, modérée par des pêcheurs.

  • Profil pêcheur
    Ville, technique, espèces favorites, badges, équipement. Pas de stalking GPS.
  • Fil régional
    Conditions du jour, prises récentes, événements, alertes locales.
  • Floutage GPS systématique
    Toute prise publique est positionnée dans un rayon de 2 km. Anti spot-burning.
  • Modération humaine
    Pêcheurs ambassadeurs régionaux + IA pour signaler les abus.
