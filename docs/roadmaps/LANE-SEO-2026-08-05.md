## Backlog ordonné

### 0. Fix sitemap (FAIT le 05/08, à déployer) 🔴
Le sitemap déclarait les **941 imports `pending`** (filtre `visibility` seul) alors que leurs fiches servent du vide (RPC filtrées `approved`) : ~80 % d'URLs mortes déclarées à Google, poison de crawl-budget et de confiance. Corrigé dans `app/sitemap.ts` (`.eq('moderation_status','approved')`), **dans le working tree, à committer/déployer avec le reste**.

### 1. Hygiène crawl (John, ~1 h, dashboard) 🔴
- **Brancher Google Search Console** (propriété domaine `carnet-de-peche.com`), soumettre `/sitemap.xml` après déploiement du fix, lire « Pages » (couverture) et « Performances » (requêtes réelles → guident le backlog guides).
- **WAF/Challenge Vercel** : 503 intermittents sur les prefetches RSC (audit 02/07 §3) = risque crawlers. Vérifier le réglage Attack Challenge Mode / règles WAF, exclure les bots légitimes.
- Re-tester le **timeout des OG images** (audit 02/07 : 25 s) sur 2-3 URLs partagées.
- Optionnel : Bing Webmaster Tools (Ecosia/DuckDuckGo s'alimentent chez Bing ; on a déjà des visiteurs Ecosia).

### 2. Curation des 941 spots importés (Claude, le levier n°1) 🔴
Playbook exécutable lot par lot : **`docs/contenu/curation-spots/PLAYBOOK.md`** + état vivant `LOTS.md`. ~800 fiches nettes publiées par vagues départementales ≈ **x5 l'inventaire indexable** avec du contenu réel (espèces, difficulté, dangers, accès, description sourcés ou honnêtement génériques). Bretagne d'abord (46 % du backlog). Chaque vague enrichit mécaniquement les landings `/spots?dept=` et `/spots?species=` déjà dans le sitemap.

### 3. Guides éditoriaux (Claude, en interstice des lots) 🟠
6 guides aujourd'hui. Cible : +10-15 sur des requêtes réelles (à recouper avec GSC dès branché). Sujets prioritaires, par intention :
- Débutant (gros volume) : « débuter la pêche en mer du bord », « quel matériel pour pêcher du bord », « pêcher avec la marée : le guide simple ».
- Local (fort intent, faible concurrence) : « où pêcher dans le Finistère (du bord) », idem 56/22/17/44 — s'appuyer sur les spots fraîchement curés, maillage direct.
- Saisonnier (marronniers) : « que pêcher en septembre/octobre… du bord », un par saison.
- Espèces/techniques manquants : compléter les combos à fort volume (dorade royale au coup, calmar/seiche du bord en automne).
Standard : même profondeur que les 6 existants, sources datées, zéro contenu creux (l'anti-Fishing Grid).

### 4. Sortir `/techniques` du « bientôt » (Claude, 1 sprint léger) 🟠
La page est en `robots: index:false` avec une liste d'attente. 4 vraies pages (leurres, surfcasting, flottante, vif) au standard fiches espèces + retrait du noindex = 4 pages piliers sur des requêtes génériques + maillage naturel espèces ↔ techniques ↔ spots.

### 5. Maillage interne (Claude, avec les vagues de curation) 🟡
Bloc « Spots proches » sur les fiches spots (même dept, distance sur `geom_public`) ; liens fiches spots → fiche espèce principale → guide technique ; les guides locaux (backlog 3) pointent vers les spots curés. Rien de nouveau à inventer côté données.

### 6. Autorité & signaux externes (César, en continu) 🟡
Backlinks : forums pêche, clubs/associations, annuaires locaux, presse locale régionale (angle « appli française de carnet de pêche ») ; liens systématiques dans les descriptions YouTube/TikTok/Instagram ; le guide RecFishing (déjà 3e page du site) est l'aimant à liens naturel : le pousser aux fédés/assos.

## Mesure & rythme

- Revue mensuelle : GSC (impressions, clics, couverture) + PostHog (`$referring_domain` moteurs, signups organiques).
- Objectif réaliste : **77 → 300 visiteurs organiques/30 j sous 8-10 semaines** après les premières vagues de curation + fix crawl ; ensuite le levier devient les guides + l'autorité.
